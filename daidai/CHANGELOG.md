# Changelog

## 0.1.0 — M1 "Seed" 🌱 (unreleased)

The first sprout of the revival.

- Fresh codebase: Kotlin 2.1, Jetpack Compose, Material 3 with dynamic color
- "Everything is an Action": `BrowserAction` catalog + JSON-persisted toolbar
  with an in-app editor (add / remove / reorder; long-press any button)
- Tabs with switcher sheet; per-tab pause/resume
- URL bar with search fallback (DuckDuckGo / Brave / Startpage / Google / Bing)
- Hosts-based ad & tracker blocking (StevenBlack default, configurable source)
- Bookmarks, find-in-page, share, desktop-site toggle
- Downloads via system DownloadManager
- en / de / ja UI
- GitHub Actions CI producing debug + release APKs
